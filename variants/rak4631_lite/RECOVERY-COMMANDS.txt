📥 ПРЯМЫЕ КОМАНДЫ (ВРУЧНУЮ):
========================================================================

1. УСТАНОВИТЕ pyocd (если еще не установлен):
   pip install pyocd

2. ПОДКЛЮЧИТЕ DAP к устройству:
   - SWDIO → DAP DATA
   - SWDCLK → DAP CLK
   - GND → DAP GND
   - VCC → DAP 3.3V (если нужно)

3. ПРОВЕРЬТЕ ПОДКЛЮЧЕНИЕ:
   pyocd list

4. СОБЕРИТЕ ПРОШИВКУ (если еще не собрана):
   cd /Users/danyloveselyi/Documents/work/my-meshtastic-fork
   pio run -e rak4631_lite

5. ПРОШИТЕ ПРОШИВКУ:
   pyocd flash -t nrf52840 -e sector .pio/build/rak4631_lite/firmware.hex

6. ПЕРЕЗАГРУЗИТЕ УСТРОЙСТВО:
 yocd commander -t nrf52840 -c reset  p
