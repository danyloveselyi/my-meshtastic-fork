# Filesystem Structure for RAK4631 Lite

Эта папка содержит всю логику файловой системы для варианта RAK4631 Lite.

## Структура папок

```
filesystem/
├── main/              # Основная файловая система (7 страниц, 28 KB)
│   ├── main-fs-pre-init.cpp      # Подготовка перед монтированием (preFSBegin)
│   └── main-fs-diagnostics.cpp  # Диагностика и инициализация (fsInitExtended)
├── nodedb/            # Расширенная файловая система для NodeDB (80 страниц, 320 KB)
│   ├── NodeDBExtendedFS.h/cpp           # Высокоуровневые операции
│   ├── NodeDBExtendedFSImpl.h/cpp      # Базовая реализация extended FS
│   └── NodeDBFilesystemAdapter.h/cpp    # Адаптер для интеграции с NodeDB
└── linker/            # Linker scripts для управления памятью
    └── nrf52840_s140_v7.ld      # Скрипт для ограничения размера приложения
```

## Основная файловая система (main/)

**Назначение**: Хранит конфигурационные файлы и общие данные приложения.

**Размер**: 7 страниц (28 KB) - стандартная конфигурация Meshtastic.

**Файлы**:
- `main-fs-pre-init.cpp` - Функция `preFSBegin()`:
  - Вызывается ДО монтирования файловой системы
  - Подготавливает flash страницы
  - Проверяет и исправляет повреждения
  - Стирает страницы при необходимости
  
- `main-fs-diagnostics.cpp` - Функция `fsInitExtended()`:
  - Вызывается ПОСЛЕ монтирования основной файловой системы
  - Выполняет детальную диагностику
  - Логирует состояние файловой системы
  - Может инициализировать расширенную файловую систему (если включена)

## Расширенная файловая система для NodeDB (nodedb/)

**Назначение**: Хранит базу данных узлов (nodes.proto) отдельно от основной файловой системы.

**Размер**: 80 страниц (320 KB) - достаточно для 400+ узлов.

**Файлы**:
- `NodeDBExtendedFS.h/cpp` - API для работы с extended FS
- `NodeDBExtendedFSImpl.h/cpp` - Реализация через LittleFS API
- `NodeDBFilesystemAdapter.h/cpp` - Адаптер, интегрирующий extended FS с основным NodeDB

**Использование**: Включается через флаг `USE_EXTENDED_FS_FOR_NODEDB` в `platformio.ini`.

## Linker scripts (linker/)

**Назначение**: Управление распределением памяти во flash.

**Файлы**:
- `nrf52840_s140_v7.ld` - Ограничивает размер приложения до 0x80000, освобождая место для extended FS.

**Статус**: Временно отключен (закомментирован в `platformio.ini`).

## Как это работает

1. **Запуск приложения**:
   - `preFSBegin()` подготавливает flash страницы
   - `FSBegin()` монтирует основную файловую систему (7 страниц)
   - `fsInitExtended()` выполняет диагностику и инициализирует extended FS (если включена)

2. **Работа с данными**:
   - Конфигурационные файлы → основная FS (7 страниц)
   - База данных узлов (nodes.proto) → extended FS (80 страниц, если включена)

3. **Интеграция**:
   - `NodeDBFilesystemAdapter` автоматически выбирает, какую FS использовать
   - Если extended FS доступна → используется она
   - Если нет → fallback на основную FS

## Преимущества такой структуры

✅ **Разделение ответственности**: Основная FS для конфигов, extended FS для больших данных  
✅ **Масштабируемость**: Легко добавить новые типы файловых систем  
✅ **Понятность**: Названия файлов и папок объясняют назначение  
✅ **Изоляция**: Логика файловой системы отделена от основного кода
